🍕 Pizza Hut Sales Analysis Using SQL

📌 Project Overview

This project focuses on analyzing Pizza Hut sales data using SQL to identify sales trends, customer preferences, and business performance.

🛠️ Tools Used

- MySQL
- SQL

🎯 Project Objectives

- Analyze total revenue.
- Identify the best-selling pizzas.
- Find the most popular pizza categories.
- Analyze customer ordering patterns.
- Calculate total orders and revenue.
- Identify sales trends.

📊 SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOINS
- Subqueries
- Aggregate Functions
- Window Functions
